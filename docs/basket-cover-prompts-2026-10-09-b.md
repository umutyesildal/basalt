# Original basket covers, batch B

Date: 2026-10-09

Twelve new original raster illustrations generated with the built-in `image_gen` tool, one call per asset. No CLI/API fallback, source photography, contact-sheet slicing or image modifications were used. Original PNGs are retained at the generator paths below. The final project assets are optimized WebP copies, as documented in the delivery format section below. Final images were visually inspected individually for subject, square composition, paper grain, the black/cream halftone style, and absence of text, logos, numbers and watermarks. Existing covers were not overwritten. The images are decorative basket identities, with no implied stock returns or issuer endorsement.

Style reference inspected before generation: `app/public/images/baskets/chip-happens.png`. This existing image was a visual style reference only and was not supplied as an edit input.
